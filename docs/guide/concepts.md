# 基础概念

在深入 AI 应用之前，了解一些基础概念会很有帮助。

## 什么是 LLM？

**大语言模型（Large Language Model, LLM）** 是基于深度学习的自然语言处理模型，通过海量文本数据训练而成。

### 主流 LLM 模型

| 模型 | 开发者 | 特点 |
|------|--------|------|
| GPT-4 | OpenAI | 多模态，能力强 |
| Claude | Anthropic | 安全性高，长文本 |
| Llama 3 | Meta | 开源，可本地部署 |
| Qwen | 阿里 | 中文优化 |
| DeepSeek | 深度求索 | 性价比高 |

## 什么是 RAG？

**检索增强生成（Retrieval-Augmented Generation, RAG）** 是一种结合检索和生成的技术：

1. **检索**：从知识库中找到相关文档
2. **增强**：将检索结果作为上下文
3. **生成**：LLM 基于上下文生成回答

```
用户问题 → 检索相关文档 → 组合上下文 → LLM 生成回答
```

## 什么是 Agent？

**AI Agent** 是具有自主决策能力的 AI 系统：

- 能够规划任务
- 调用工具
- 根据反馈调整策略
- 完成复杂目标

Hermes Agent 就是一个典型的 AI Agent 示例。

## 什么是 Embedding？

**向量嵌入（Embedding）** 是将文本转换为数值向量的技术：

```python
# 概念示意
"今天天气真好" → [0.2, 0.8, 0.1, 0.5, ...]  # 768维向量
```

向量可以用于：
- 语义相似度计算
- 知识库检索
- 推荐系统
