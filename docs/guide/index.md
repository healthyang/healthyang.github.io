## 快速开始

如果你是新手，建议从 [环境搭建](/guide/setup) 开始：

```bash
# 1. 确保已安装 Node.js
node --version

# 2. 克隆站点仓库
git clone https://github.com/healthyang/healthyang.github.io.git
cd healthyang.github.io

# 3. 本地预览
npm install
npm run docs:dev
```
