## 🔍 SearXNG 隐私搜索引擎部署

### 做了什么

在内网服务器上用 Docker Compose 部署了 [SearXNG](https://github.com/searxng/searxng) 隐私搜索引擎，并将其作为 Hermes Agent 的搜索后端。

### 关键配置

```yaml
# docker-compose.yml 核心配置
services:
  searxng:
    image: searxng/searxng:latest
    ports:
      - "8080:8080"
    volumes:
      - ./searxng:/etc/searxng
    environment:
      - SEARXNG_BASE_URL=http://localhost:8080
```

搜索引擎配置重点：
- 启用百度、必应、搜狗等国内引擎（覆盖中文搜索需求）
- 禁用需要验证码的引擎（避免自动化失败）
- 配置 `autocomplete` 为 `duckduckgo`（搜索建议）

### 踩坑记录

1. **端口冲突**：默认 8888 端口被占用，改为 8080
2. **搜索引擎初始化慢**：首次启动需要拉取引擎配置，耐心等待 30 秒
3. **Hermes Agent 调用失败**：需要在 Agent 配置中明确指定 `SEARXNG_URL` 环境变量

### 收获

SearXNG 轻量且功能强大，适合自托管场景。作为 AI Agent 的搜索后端，比直接调用商业化搜索 API 更可控、更隐私。

## 🚀 VitePress 静态站点搭建

### 做了什么

将原本的 Jekyll 博客迁移到 VitePress，搭建了这个 AI 学习笔记站点（就是你现在看到的这个网站）。

### 为什么选 VitePress

| 对比项 | Jekyll | VitePress |
|--------|--------|-----------|
| 构建速度 | 慢（Ruby） | 快（Vite） |
| 热重载 | 不支持 | 支持 |
| Markdown 扩展 | 基础 | 丰富（容器、自定义容器） |
| 主题定制 | 需要写 Liquid | Vue 组件，更灵活 |
| 部署 | GitHub Pages 原生 | 需要构建步骤 |

### 关键配置

```ts
// docs/.vitepress/config.ts 核心配置
export default defineConfig({
  title: 'AI 学习笔记',
  description: 'AI 应用学习知识分享',
  base: '/',  // GitHub Pages 子路径时需要改
  
  themeConfig: {
    nav: [
      { text: '首页', link: '/' },
      { text: '入门指南', link: '/guide/' },
    ],
    sidebar: { /* ... */ }
  }
})
```

### 部署流程

```
本地开发 (npm run docs:dev)
    ↓
提交代码到 main 分支
    ↓
GitHub Actions 自动触发
    ↓
npm install → npm run docs:build
    ↓
部署到 GitHub Pages
```

GitHub Actions 配置文件：`.github/workflows/deploy.yml`

### 踩坑记录

1. **GitHub Pages 404**：`base` 配置错误，应该是 `/` 而不是 `/ai-learning-notes/`
2. **构建失败**：`package-lock.json` 被 `.gitignore` 排除，导致 CI 依赖版本不一致
3. **RSS 插件报错**：`vitepress-plugin-rss` 需要在 `vite.plugins` 里配置，不能直接放 `plugins`

### 收获

VitePress 的热重载和构建速度非常快，本地开发体验很好。Vue 组件系统比 Jekyll 的 Liquid 模板灵活太多，未来可以做更多交互式内容。
