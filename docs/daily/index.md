# 学习日记

记录每日 AI 学习的心得与发现。

## 2026 年 5 月

### 5 月 27 日 - 搭建 VitePress 站点

今天开始搭建 AI 学习知识分享站点：

- 使用 VitePress 替代 Jekyll，获得更好的开发体验
- 配置了中文界面和导航结构
- 创建了基础内容框架
- 设置了 GitHub Actions 自动部署

**收获**：VitePress 的热重载和构建速度非常快，本地开发体验很好。

---

### 5 月 25 日 - SearXNG 部署

成功在内网服务器部署 SearXNG 隐私搜索引擎：

- 使用 Docker Compose 部署
- 配置了百度、必应、搜狗等国内搜索引擎
- 解决了 GFW 导致的国际引擎不可用问题
- 将其作为 Hermes Agent 的搜索后端

**收获**：SearXNG 轻量且功能强大，适合自托管场景。
