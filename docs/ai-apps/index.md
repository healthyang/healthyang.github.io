## 技术栈

本系列实战使用的主要技术：

- **容器化**: Docker + Docker Compose
- **搜索引擎**: SearXNG
- **AI 平台**: Dify
- **LLM 推理**: vLLM / llama.cpp
- **开发工具**: Hermes Agent, VS Code
