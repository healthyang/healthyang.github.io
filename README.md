## 🛠️ 本地开发

```bash
# 克隆仓库
git clone https://github.com/healthyang/healthyang.github.io.git
cd healthyang.github.io

# 安装依赖
npm install

# 启动开发服务器
npm run docs:dev
```

## 📦 技术栈

- [VitePress](https://vitepress.dev/) - 静态站点生成器
- [GitHub Actions](https://docs.github.com/actions) - 自动构建部署
- [GitHub Pages](https://pages.github.com/) - 免费托管

## 📝 添加内容

1. 在 `docs/` 目录下创建或编辑 `.md` 文件
2. 提交并推送代码
3. GitHub Actions 自动构建部署
